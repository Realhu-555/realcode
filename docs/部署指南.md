# GIS 智能助手部署指南（T13）

> 适用版本：v0.2（工具 20 个，agent 补强完成）。配套方案见 `docs/GIS-助手工程化与上线方案.md`。
> 目标：新机器按本文档 10 分钟内跑起来。

## 形态 A：Windows 本机（推荐试用）

### 1. 前置环境
- Python 3.12+，Node.js 18+（仅 dsh 入口需要）
- QGIS LTR（推荐 3.40+，安装到 `D:\QGIS`；只用 geopandas 引擎可跳过）

### 2. 安装
```bat
cd ai-dev-platform
python -m venv venv
call venv\Scripts\activate.bat
pip install -e ".[dev]"
copy .env.example .env
```
编辑 `.env` 填入 `DEEPSEEK_API_KEY`（必需）；`GIS_ENGINE=geopandas|qgis` 切换引擎。

### 3. 启动后端
```bat
start.bat
```
健康检查：`http://localhost:8080/api/health`

### 4. 验证
```bat
call scripts\check.bat
```
或单跑冒烟：`python scripts\smoke.py`（见 T15）。

### 5.（可选）dsh 入口
- DSH Desktop 已配置 MCP Server（`gis-mcp`）时直接使用；
- 手动配置：`~/.dsh/profiles/desktop/cordis.patch.yml` 挂载 `@deepseek-ai/dsh-mcp-client`，command 指向 `venv/Scripts/python.exe src/gis_mcp/server.py`。

## 形态 B：Docker（服务器）

### 1. 构建与启动
```bash
docker compose up -d
```
> 注意：QGIS 引擎需要 QGIS 环境（镜像内装 `qgis` 或走 qgis_process 服务）；仅 geopandas 引擎可直接用现有 `Dockerfile`。

### 2. 验证
```bash
curl http://localhost:8080/api/health
```

## 常见问题
| 现象 | 处理 |
|---|---|
| 后端 8080 起不来 | 检查 `.env` 的 `DEEPSEEK_API_KEY`；端口被占用改 `start.bat` 端口 |
| `GIS_ENGINE=qgis` 报未找到 QGIS | 安装 QGIS 或设置 `QGIS_PREFIX_PATH` 指向 `apps/qgis-ltr` |
| MCP 工具在 dsh 里不可见 | 重启 DSH Desktop；确认 `gis_mcp/server.py` 可被 venv python 运行 |
| pytest 临时目录权限错误 | 用 `scripts\check.bat`（已带 `--basetemp`） |
