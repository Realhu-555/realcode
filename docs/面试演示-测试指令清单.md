## 0. 开演前 2 分钟自检

1. 打开 http://localhost:8080/gis → 页面正常、能新建会话；
2. 发一条最小指令探活："你好，你能做什么？"（或"列出你能帮我做的 GIS 操作"）；
3. 确认模型有响应、产物卡片能下载；
4. 截图 3 张（对话页/出图/审批）兜底，录音屏工具就绪。

## 1. 第一幕：看得懂（建立信任，各 30~40 秒）

**1-1 自报家门**
> 你能做什么？把你的能力按"读数据/空间分析/出图/编辑/工程管理"分类列给我，各给一个例子。
预期：结构化能力清单 + 示例，展示系统不是单点 demo。

**1-2 探查数据（先了解再干活）**
> 加载 data/gis_demo/gdp_demo.csv，先看字段和样例，再告诉我适合做哪些分析。
预期：load→inspect 两步，输出字段/行数/CRS/样例；最后给你建议。

**1-3 了解工程/图层（★A 方案：QGIS live）**
> 当前 QGIS 工程里有哪些图层？每个图层的要素数和坐标系是多少？
预期：列出真实图层（需 QGIS 已开 + 插件在线）。

## 2. 第二幕：会分析（主推，1~2 分钟）

**2-1 字段统计 → 出分级设色图（最稳，强烈推荐开场）**
> 加载 data/gis_demo/china_population.csv（列：province/gdp/pop），先对 pop 列做字段统计，再按省份用 pop 做一张分级设色图，解释一下人口分布。
预期：统计（均值/最大/最小/缺失）→ choropleth PNG 即时预览 → 用大白话讲"东部沿海/川渝高，西部低"。

**2-2 GDP 省际对比**
> 加载 data/gis_demo/gdp_demo.csv，按省份汇总 GDP，按省画分级设色图并说明前三名。
预期：summarize(按省聚合) → 出图 → 文本结论（前三省）。

**2-3 空间分析（展示"真 GIS 运算"）**
> 加载 data/gis_base/guangdong_cities_points.geojson，对每个市做 0.02 度缓冲区，再导出成 GeoJSON。
预期：buffer 结果 + 可下载 geojson；可追问"这些市里离广州最近的是哪个"走 spatial join。

## 3. 第三幕：能操作 + 安全（差异点，2~3 分钟）

> ⚠️ B 方案也能演示审批卡（内存编辑 + 人工审批），差异只是结果不落在 QGIS 图层树而是文件/表。

**3-1 审批演示（核心台词位）**
> 加载 data/gis_base/china_province.geojson，把 name 为 '广东省' 的要素的 adcode 改成 999999。
预期：触发危险操作 → 弹审批卡 → 现场点"同意" → 成功并提示可回滚。
台词："注意，AI 要动我的数据，必须先经我确认——这是企业敢用的底线。"

**3-2 完整编辑闭环**
> 复制当前图层为 bak；在 bak 上开始编辑；新增字段 note 并给所有要素填'已检查'；提交编辑；导出 bak 为 GeoJSON。
预期：duplicate→start_editing→calculate/update→commit→export 多步链，审批出现在写操作前。

**3-3 失败与兜底（加分项，演示"错误可留痕"）**
> 故意来一句不可能完成的："把当前图层飞到月球再回来"。
预期：Agent 给出明确拒绝或转说明（无工具可达 → 不做或转人工式回复）。这正好讲"不是啥都硬答，有边界"。

## 6. 追问演示（产品/Agent 深度问题配套）

- **"它怎么知道自己该干嘛？"** → 现场发："我不知道这个数据是什么，你自己看着办，给我一个最有价值的分析"。看它自主 load→inspect→选方案→出图。
- **"会不会越聊越乱/记不住前面？"** → 现场发长链：先"加载 gdp_demo" → 再"刚才那张图按省份汇总，导出 csv" → 再"把汇总结果转成分级设色图"。看它跨轮复用前文结论（记忆/上下文）。
- **"怎么证明效果不是自嗨？"** → 讲 455 测试 + 评测集口径，不必现场跑。

## 7. A 方案（QGIS live）切换清单 —— 面试前 10 分钟执行

如果对方想看"结果真实落进 GIS 图层树"，用 A 方案：
1. 打开 QGIS → 插件菜单勾选「GIS Assistant Live」→ 打开面板（确认本地服务 8756 在线）；
2. `.env` 把 `GIS_ENGINE=geopandas` 改回 `GIS_ENGINE=live`；
3. 重启后端（我这边一键脚本已备好）；
4. 用 3-2 指令验证：图层出现在 QGIS 图层树；
5. **强烈建议同时保留录屏**——live 链路多一个 QGIS 环节，最怕现场崩。

切回 B：改 `GIS_ENGINE=geopandas` + 重启即可（当前就是 B）。

## 8. 翻车急救（重复卡片提示）

| 症状 | 处理 |

| 模型没反应/网络挂 | "稍等切备用"→ 放录屏/讲截图 |
