完整执行流程
1

输入处理

用户提交需求（纯文本 / Word / PDF / 图片 / 网页链接 / Excel）。系统自动识别输入类型，调用对应 Loader 提取文本。多种输入可混合使用。

DocumentLoader ImageDescriber WebExtractor
2

需求分析 · Requirement Agent

Plan-and-Execute 模式。先分析需求、拆功能模块、排优先级，再生成 PRD 文档。如果信息不足会追问用户。完成后暂停等用户确认。

Plan-and-Execute 人工确认 PRD
3

架构设计 · Architect Agent

Plan-and-Execute 模式。基于 PRD 选技术栈、设计数据模型、定义 API 接口。可调用 web_search 查技术文档。完成后暂停等用户确认。

Plan-and-Execute web_search 人工确认方案
4

并行开发 · Backend + Frontend Agent

ReAct 模式，两个 Agent 并行执行。每个 Agent 循环：思考→写文件→跑命令→观察结果→修正。能自己发现语法错误并修复。完成后暂停等用户确认。

ReAct file_read/write terminal sandbox 人工确认代码
5

测试验证 · Tester Agent

ReAct + Reflection 模式。读源码→写测试→跑 pytest→分析结果。失败时自动回退到 Backend/Frontend 修复 bug（最多 3 次）。超过 3 次交给用户。

ReAct + Reflection Bug 回退循环（≤3 次） 超限人工介入
6

部署打包 · Deployer Agent

ReAct 模式。检查代码完整性→打包 ZIP→输出下载链接。无需人工确认，自动执行。

ReAct terminal
7

记忆沉淀（自动）

项目完成后自动执行：项目记录存 SQLite → Agent 总结经验教训 → 经验向量化存 ChromaDB → 用户偏好更新。下个项目自动读取这些经验。

SQLite ChromaDB
记忆机制设计

📥 短期记忆（项目内）

SQLite 存储，项目结束归档

存什么用户输入、Agent 产出、追问历史、用户修改意见、测试结果
谁写入Orchestrator（每个阶段完成后自动保存）
谁读取每个 Agent 执行前，读取完整项目上下文
价值Backend Agent 能看到用户的追问结果、前端组件设计，不会漏功能

📤 长期记忆（跨项目）

SQLite（结构化）+ ChromaDB（语义检索），永久保存

SQLite 存项目记录（技术栈/状态）、用户偏好（UI 框架/模型选择）、模型性能统计
ChromaDB 存历史技术方案、经验教训、代码片段（向量化后语义检索）
写入时机项目完成后，Agent 自动总结经验教训
读取时机新项目启动时，用需求语义检索类似项目经验，注入 Agent prompt

🔄 记忆生命周期

1. 项目启动 → 检索长期记忆（类似项目经验）→ 注入 Agent prompt
2. 执行中 → 每个 Agent 产出写入短期记忆
3. 用户反馈 → 修改意见写入短期记忆
4. 项目完成 → Agent 总结经验 → 存入长期记忆
5. 下个项目 → 自动读取经验 → 越做越聪明
